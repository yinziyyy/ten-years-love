# 第31章 细纲：报到日

- 核心事件：市非遗馆报到：交验资料、抽序、封闭区规则宣讲与场地踩点；协调会散会后他先问「你需要什么」，她把「材料避光恒温存放」的需求说得具体；他指给她对全体选手开放的正规申请通道，她按流程申请获批；他停在会务区，不进选手区一步。
- 字数目标：2500 字
- 字数口径：visible_chars_v1
- 阶段位置：发展期主体第31章（第二卷开篇）；报到与备赛起点
- 单元ID/位置：V2-U1（第1拍：报到与并肩——他先问「你需要什么」）
- 目标情绪：报到的忙与兴奋 → 被问「你需要什么」的认真（她这次要说具体）→ 边界感里的安心
- 主角目标/关键选择：她要顺顺当当办完报到、把材料安顿好；关键选择＝不用「他方便」的资源——把需求放进对全体选手开放的申请通道，走正门解决
- 章节定位：低压生活
- 本章结构公式：报到（交验与抽序）＋封闭区宣讲（规则）＋他的问题（你需要什么）＋申请通道（合规解决）
- 章首钩子：场景开局——报到处的队不长，每个人的资料袋都装在一样的透明文件袋里。
- 爽点：微甜点——「你需要什么」被落实成一个具体需求；规则被念出来时的心安
- 本章标价：尺1（第1点）：报到资料的分量——在册、封样、清单，一样不能少；尺2（第4点）：一个申请通道的价——从正门进来的帮助，谁也不用欠谁
- 闭环状态：报到拍完成；「他的接近有边界」立住（他不进选手区）；备赛开始（接第 32 章）
- 本章禁止提前释放：不让他进入选手封闭区、修复操作区与评审环节；不写成他直接替她搞定；不重复念叨「你决定」
- 写手自由区：报到流程的秩序感、封闭区宣讲的现场声、申请通道公告栏的样式、她和他在会务区门口的距离
- 契约风险：契约安全

### 内容概括（五段式）

- 起因：报到日。资料交验、抽序、封闭区规则宣讲——选手区、修复操作区、材料暂存区的边界一条条念清楚；她核对完最后一页，签了字。
- 发展：她踩点修复操作区，发现问题：自己那排材料暂存位朝西，下午的太阳正对着柜面。
- 转折：协调会散场——他今天来，是作为支持单位代表参会的。他在会务区门口等她，先问：「你需要什么。」这一次，她没客气也没绕——把「避光恒温存放位」说了，具体到柜位朝向。
- 高潮：他没有说「我来办」，只指了指公告栏上的申请通道——「对全体选手开放，今天提，明天调。」她当场填了申请；傍晚，通知下来：她那排整体加装遮光帘。
- 结尾：她回头看了一眼会务区：他正低头看自己的会议材料，没有往选手区走一步。
