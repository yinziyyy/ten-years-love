# 第1章 细纲：我要阿阮修

- 核心事件：傅衍舟携傅家祖传霁蓝盏到市博物馆送修，提出希望由「阿阮」主修（「我要阿阮修。」）——全馆无人知道阿阮是谁，只有做检测记录的温阮自己知道。
- 字数目标：2500 字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期（第1-15章）第1章；黄金三章之首：立人设、立悬念、立信息差
- 单元ID/位置：V1-U1（第1拍：建立期待）
- 目标情绪：平静压抑（小透明与「被点名」的错位）→ 惊涛压面（全场静默，「阿阮」二字砸在温阮身上）——从「没人注意她」到「他的目光停在她的手上」
- 主角目标/关键选择：温阮只想安静做完手里的活、不回应点名；她必须做出的判断是——按住身份不动（在「阿阮」被全馆寻找的当口，沉默是她唯一的选择）
- 章节定位：高压
- 本章结构公式：日常小场景（工位修碎片）＋异常来客（大人物亲自送修）＋当众点名（我要阿阮修）＋目光落点（他看了她的手）
- 章首钩子：未完成动作开局——竹刀悬在碎片上方一毫米，门被推开
- 爽点：无显性爽点；期待点＝「阿阮是谁」的信息差张力（读者握着她就是阿阮的牌，看她如何在全场搜寻里不动声色）
- 本章标价：两把尺在第3、5点前立好——①盏的分量：借唐时野念单与同事反应立起「这单大得离谱」的器物尺；②「阿阮」的名义价：同事们打电话四处打听，联系不上、没人见过——「阿阮」是圈内传说（身份尺）
- 闭环状态：本章不闭环；断点＝「接不接单」的注押在第4点（她的沉默），第2-4章开奖
- 本章禁止提前释放：他＝「衍」（留到第 22 章）；「阿阮＝温阮」对馆内任何人成立；盏底暗记
- 写手自由区：修复组同事的众生相反应（谁先凑近看盏、谁偷偷拍照发群）、唐时野念送修单的腔调、温阮手里的碎片是哪一件日常在修物（自选）、会客厅的光影
- 契约风险：契约安全

### 内容概括（五段式）

- 起因：傅氏资本一笔「指定修复」的送修单递进江城市博物馆——送修人要求面交，点名传说级手作大神「阿阮」主修。
- 发展：傅衍舟与助理唐时野到馆，馆长周明德亲自接待，修复组全员列席。送修单手续、器物分量逐一铺开，全组被祖传霁蓝盏压住——紧跟着那句「唯一要求」把所有人钉在原地。
- 转折：周明德和同事们把「阿阮」搜了个遍——电话、人脉、私信——全部落空。一直低头记录的温阮，指节捏白。
- 高潮：傅衍舟越过所有人，把最后一句话放到台面上：「我要阿阮修。」会客厅落针可闻。
- 结尾：他的目光扫过一圈，最终在温阮握镊子的手上停了一瞬——比别处多一秒。她把镊子捏得更紧，没有抬头。

### 情节安排（多线）

- 主线推进：送修单落地→「希望阿阮主修」成为全馆硬指标，「阿阮」进入被寻找状态（L03 身份线开局）
- 辅线推进：L01 从「隔屏守望」推到「他走进她的同一空间」；L02 从「小透明」推到「关键项目在场记录者」
- 事件线 / 任务线：傅氏资本的祖传器物修复委托（合规送修）；卡点＝唯一要求「阿阮主修」无人能认领
- 任务卡点（如适用）：无
- 感情线 / 关系线：无显性互动；他单方面的目光落点与她的僵直手指，构成第一次「隔空触碰」
- 逻辑线：大人物亲自送修→事情反常→他提出无法满足的要求→悬念从「谁来修」变成「他为什么知道阿阮」

### 人物关系和出场顺序

- 出场顺序：温阮（工作间开场）→ 周明德（通知接待）→ 傅衍舟、唐时野（到馆）→ 谢云筝与修复组同事（列席）
- 镜头准入：台词位＝周明德（场面话）、唐时野（念单）、傅衍舟（一句话定乾坤）、谢云筝（一句表态）；温阮以动作位与内心位在场，全章只出一句工作句
- 人物关系变化：温阮×傅衍舟（无关系→被单方面锁定的起点）；温阮×周明德（平时「隐形人」状态被打破）
- 视角/信息差：第三人称限视（温阮主视角）。读者本章获得三层信息：她是阿阮（她自知）、他提出希望阿阮主修（全场不知为何）、他看她的手（只有读者觉得不对）。温阮误判：这只是「粉丝找上门」的麻烦
- 信息差触发点：第4点——他把要求压到台面时，读者因知道她是阿阮而紧绷；第6点——目光落点，用「比别处多一秒」把信息差递给读者

### 结尾设定和钩子

- 结尾设定：会客厅散场前，他只留下一句「先检测——我等你们的说法」。温阮最后一个离开，回头看了一眼被重新锁进保险箱的盏——她的手，抖了一下。
- 章尾钩子：隐藏含义——他扫过所有人的脸，最后在她的手上停了一瞬。没有人注意到，那一瞬比别处多了一秒；而她的镊子，第一次没拿稳。
