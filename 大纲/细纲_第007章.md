# 第7章 细纲：一张十年前的截图

- 核心事件：她熬夜回看十年直播，发现一个 ID「衍」几乎每晚都在；白天又在送修附件里翻出一张十年前的直播截图——她修第一只碗的那个晚上。
- 字数目标：2500 字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期第7章；双线拼图章
- 单元ID/位置：V1-U2（第3拍：甜点与疑点）
- 目标情绪：考古般的入迷（回放里的旧时光）→ 心跳（那个 ID）→ 背脊又凉又热（截图上的弹幕水印）
- 主角目标/关键选择：她想弄清「送修资料里为什么有这张截图」；关键选择＝不直接问他，先自己把证据摆齐（手艺人逻辑：先检测，再下结论）
- 章节定位：推进
- 本章结构公式：回放审计（发现「衍」）＋检测记录（碎口编号与试拼）＋附件截图（突兀出现）＋对照（拼图成立一半）
- 章首钩子：闪前碎片——「如果那天她把进度条拖回开头，或者干脆没打开那个文件夹，也许一切都会不一样。」
- 爽点：无显性爽点；看点＝「拼图感」——读者比她多拼一块
- 本章标价：尺1（第2点）：回放里「衍」的出现密度——十年几乎每晚（时间尺）；尺2（第4点）：这张截图的信息价——它出现在送修资料里，说明寄件人当年就在看（证据尺）
- 闭环状态：F5 形成初步关联：本章只确认长期观众 ID 与送修附件之间的联系。第 22 章由温阮直接询问，傅衍舟当面确认自己就是「衍」。第 78 章补充资料来源、现实介入范围和爱情形成时间，不再重复揭晓真人身份。
- 本章禁止提前释放：不得确认「衍」＝傅衍舟（本限制仅限本章——真人确认按连续性总表的身份分工在第 22 章当面完成，不许延后）；他的动机全貌；截图的完整含义
- 写手自由区：回放的年代感（早期直播的糊画质、弹幕梗）、她发现「衍」时的动作设计、检测与记录工序的专业质感
- 契约风险：契约安全

### 内容概括（五段式）

- 起因：她本打算只看十分钟——结果从第一场看到了后半夜。十年前的直播间只有个位数的观众，十六岁的她对着屏幕说「晚安」。
- 发展：她做了件自己都意外的事：把弹幕导出来，按 ID 排序。老观众来来去去，只有一个 ID 几乎每晚都在，很少说话，偶尔四个字：「不错啊。」「加油。」
- 转折：那个 ID，叫「衍」。
- 高潮：白天，她在送修附件里翻出一张打印截图——画面上是十年前的直播：她低着头，修一只素白瓷碗。截图右下角，悬着一条没发完的弹幕：「衍：今天也……」
- 结尾：她把截图翻过来，背面空白。她盯着看了很久，最后把它和装着竹刀的抽屉，放进同一个柜格。

### 情节安排（多线）

- 主线推进：L01 从「他被物件代言」推进到「他的痕迹第一次被正面看见」；L03 她开始主动审计自己的历史（自我真相线）
- 辅线推进：L02 推进到检测记录与试样准备；L05 静默蓄力
- 事件线 / 任务线：送修资料的复核（她借「核对附件」之名行「查他」之实）
- 任务卡点（如适用）：无
- 感情线 / 关系线：无显性对话；「衍」与截图把男主角的存在感拉满，为第8章的「恰好清单」升级铺垫
- 逻辑线：她夜里回看→发现 ID→白天核对附件→发现截图→两条证据并在案头→她开始怀疑「送修人想让她看见什么」

### 人物关系和出场顺序

- 出场顺序：温阮（深夜/后半夜）→ 馆内同事（背景）→ 温阮（附件室/工位）
- 镜头准入：整章基本独角戏；同事仅以背景声存在；不引入新人物
- 人物关系变化：温阮×「衍」（陌生人→她把一个 ID 记进了心里）；对傅衍舟的观感开始与「衍」叠影（她尚未自认）
- 视角/信息差：读者掌握「他看了她十年」的轮廓；她只到「有个 ID 叫『衍』的观众，几乎每晚都在」。她对傅衍舟的误判开始松动
- 信息差触发点：第5点——水印重合时，用一个极小的动作（指尖停住）提醒读者：两条线接上了

### 结尾设定和钩子

- 结尾设定：她关柜门前又看了一眼。柜格里：竹刀、截图、还有她随手放进去的检测笔——三样东西安静地排成一列。
- 章尾钩子：隐藏含义——截图右下角那条没发完的弹幕，和抽屉里的竹刀，指向同一个人。她第一次想：「你到底是让我修盏，还是让我看见你？」
