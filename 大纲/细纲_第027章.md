# 第27章 细纲：生日局

- 核心事件：苏芒生日局：朋友起哄「傅总究竟几层意图」，温阮笑着绕开；她送给苏芒的礼物是一只被金缮修好的旧发簪；苏芒以粉丝口吻聊「阿阮复播」，温阮面不改色。散场后，手机亮起：「明天下午，馆门口。」
- 字数目标：2500 字
- 字数口径：visible_chars_v1
- 阶段位置：发展期开端第27章；社交日常与感情蓄势
- 单元ID/位置：V1-U5（第5拍：甜点群——朋友场与心意）
- 目标情绪：热闹的松弛（先过生日）→ 被起哄的会心（她发现自己没有否认）→ 散场后的一点心跳（那条消息）
- 主角目标/关键选择：她要好好给朋友过生日；关键选择＝不确认、不否认、不扫兴——用玩笑守住自己的答案，把它留给自己
- 章节定位：低压生活
- 本章结构公式：生日局（热）＋起哄（闹）＋礼物（金缮发簪）＋粉丝闲谈（信息差喜剧）＋散场消息（钩）
- 章首钩子：反差场景——生日蜡烛插在火锅店的小蛋糕上；许愿的人只有一个，起哄的人有六七个。
- 爽点：轻甜点——金缮发簪让寿星当场尖叫；她把起哄原样弹回去
- 本章标价：尺1（第2点）：起哄的价——朋友们越热闹，她越清楚这件事还没到说的时候；尺2（第3点）：那支发簪的价——修好一件旧东西，是她用来爱人的方式
- 闭环状态：不闭环；L06 生日局兑现（社交线）；她的答案留到第 29 章自己认；「明天」接第 28 章
- 本章禁止提前释放：苏芒不知「温阮＝阿阮」（第 50 章才确认）；不确认恋爱关系；朋友不提前得知十年档案
- 写手自由区：火锅局的烟火气与朋友群像、起哄的火力配比、发簪修口的工艺呈现（点到为止）、苏芒的粉丝狂热度
- 契约风险：契约安全

### 内容概括（五段式）

- 起因：苏芒生日，火锅、蛋糕、一群朋友。她来得最早，礼物藏在包里——是一只学生时代的旧发簪，断口上被她用金缮接出一道细线。
- 发展：酒过三巡，起哄开始：「傅总究竟几层意图？」温阮把毛肚涮了十秒，回：「几层我不知道；你们几位今天倒是很敢。」一桌人笑翻。
- 转折：拆礼物——「你什么时候修的！」「上个月，你搬家丢在我那儿的时候。」苏芒当场戴上，对镜子看了三遍。
- 高潮：苏芒边看手机边念超话：「阿阮复播啦！我蹲到了！你们知道我蹲了多久吗——」温阮喝了口可乐：「是吗，那挺好。」（全场只有读者知道笑点在哪）
- 结尾：散场，她在路边等车。手机亮起——一条消息躺在那里：「明天下午，馆门口。」发件人：傅衍舟。
