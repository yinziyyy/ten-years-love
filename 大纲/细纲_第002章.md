# 第2章 细纲：盏底旧痕

- 核心事件：全馆为找不到「阿阮」焦头烂额；温阮被指派做霁蓝盏入馆检测，在盏底认出一处 2005 年修复留下的旧补痕——外婆阮秀和的金缮暗记。
- 字数目标：2500 字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期第2章；黄金三章之二
- 单元ID/位置：V1-U1（第2拍：加压/转向）
- 目标情绪：兵荒马乱（怎么找到阿阮）→ 心口一沉（她认出了外婆的痕迹）→ 发冷（她决定不碰，理由却说不出口）
- 主角目标/关键选择：她必须决定「要不要碰这盏」；关键选择＝向馆里表态「这单不该由我碰」，同时不说真实理由（护住身份，也护住旧事）
- 章节定位：高压
- 本章结构公式：群体焦头烂额（找人）＋她被推到台前（指定做检测）＋近距离相认（盏底旧痕）＋失态与压回（她说不碰）
- 章首钩子：反差场景——一边是会议室为「找不到阿阮」吵成一团，一边是检测台上，盏静静躺着，像在等人
- 爽点：无显性爽点；看点＝「她一眼认出别人看不懂的东西」的专业视角，与「只有她知道不能碰」的压迫感
- 本章标价：尺1（第1点立）：这单是馆里年度重点项目——推掉它＝得罪送修方、组里绩效打折；尺2（第4点立）：家族禁忌的代价——母亲当年那句「别碰」还挂在微信置顶（与傅家旧事相关）
- 闭环状态：本章不闭环。「获得」拍（暗记信息到手）已走；兑付（这是谁的痕迹、意味着什么）扣在第9章
- 本章禁止提前释放：阮秀和与旧案全貌；旧补痕＝外婆手笔的公开表达（停在「她认得这道痕」）
- 写手自由区：检测流程的专业细节（灯下看胎骨、探针、放大镜）、找阿阮的荒诞众相、谢云筝那句阴阳的落点
- 契约风险：契约安全

### 内容概括（五段式）

- 起因：傅衍舟留下「先检测」的话走了，全馆开始为「阿阮」疯狂找人——电话、人脉、后台私信，全部石沉大海。
- 发展：周明德拍板：先把盏接进来做入馆检测，「谁修，等检测和方案出来再说」。最细致的检测记录一向是温阮做的——她被指派上手。
- 转折：灯下，她顺着盏底看过去——一道旧补痕。收笔回锋、金线暗走成半个「和」字的习惯，是她从小看到大的东西。
- 高潮：同事催她出检测意见，她喉咙发紧，说出与专业无关的一句：「这单……建议别接。」理由一个字都给不出。
- 结尾：夜里回家，她把盏底灰的照片放大，和手机相册里一张外婆工作台的旧照片并排放在一起——收笔，一模一样。

### 情节安排（多线）

- 主线推进：盏入馆检测启动；「她认得这道痕」成为她与读者握住的第一个实体线索（L05 微电波起点）
- 辅线推进：L04 谢云筝首次对「温阮碰盏」产生警觉与讥讽；L02 从「记录者」推到「被指派检测人」
- 事件线 / 任务线：找阿阮（失败）＋入馆检测（进行）
- 任务卡点（如适用）：找阿阮处处碰壁——功能＝选择压力，把「接不接」的压力推给她
- 感情线 / 关系线：无显性互动；盏作为「他留下的东西」第一次在她私人时间被端详
- 逻辑线：找不到阿阮→先做检测→她被迫近距离接触→认出旧痕→她反常地建议别接→理由成谜

### 人物关系和出场顺序

- 出场顺序：周明德与同事（找人会议）→ 谢云筝（指派环节抢话）→ 温阮（检测台）→ 母亲（以微信置顶的形式存在，未出场）
- 镜头准入：台词位＝周明德、谢云筝、同事甲；温阮两句（工作句＋反常建议）；母亲以屏幕形式存在
- 人物关系变化：温阮×谢云筝（和气同门→谢第一次对她「反常」起疑）；温阮×周明德（被指派→被质疑「一个做记录的懂什么」）
- 视角/信息差：读者层层领先——知道她是阿阮、知道她认得这道痕；馆里众人只当她是「那个做记录的」。她的误判：以为只要不接，就与旧事无关
- 信息差触发点：第4点——她盯着旧痕时，用同事一句「你看什么呢」把读者的紧张提醒一次

### 结尾设定和钩子

- 结尾设定：两张照片并排放在桌上，收笔角度重合。她把手机扣下，盯着看了很久，最后只做了一件事——把照片加密收藏。
