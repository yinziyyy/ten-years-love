# 第25章 细纲：两个屏幕

- 核心事件：她时隔许久重新开播；开播前给他发了一句「别刷礼物」；他坐在另一块屏幕前看完整场，末尾发了一条弹幕：「不错啊。」
- 字数目标：2500 字
- 字数口径：visible_chars_v1
- 阶段位置：发展期开端第25章；甜点群起点，明牌相处的第一次对望
- 单元ID/位置：V1-U5（第3拍：甜点群起点——明牌对望）
- 目标情绪：重新开播的轻紧（镜头亮起来）→ 明牌的静（他在看，她知道）→ 收梢的软（一条弹幕落在心口）
- 主角目标/关键选择：她要重新站回自己的直播间（为手艺，为自己）；关键选择＝开播前主动给他立一条小规矩：「别刷礼物。」——把这个地方守住成「作品说话」的地方
- 章节定位：关系回收（低压）
- 本章结构公式：开播决定＋一句规矩（明牌互动）＋直播间的十年与今夜（视角对照）＋他的弹幕（复沓）
- 章首钩子：未完成动作开局——手机架好、补光灯亮起来之前，她先发了一条消息。
- 爽点：无显性爽点；看点＝十年「隔屏」与今晚「明牌」的安静对照
- 本章标价：尺1（第2点）：直播间的价——这是她唯一不为任何人开的地方；尺2（第5点）：一条弹幕的价——三个字，发了十年，今晚第一次当着「知道」发出来
- 闭环状态：L01「明牌相处」拍落地；心动（第 29 章）继续欠着；直播线的「重新开播」停在此处，不预告后续
- 本章禁止提前释放：不写恋爱关系确认；不写他送任何礼物；不向直播间观众解释「衍」的在场
- 写手自由区：直播间的摆位与光线、老观众弹幕的梗、她讲解时的松弛度、他那边房间的陈设与声音处理
- 契约风险：契约安全

### 内容概括（五段式）

- 起因：她决定重新开播：镜头、角度、「不露脸」的规矩，一切照旧。开播前，她给他发了一条消息：「今晚九点。别刷礼物。」
- 发展：直播间涌进老观众——「失踪人口回归」「还以为你退圈了」；她修着手里的练习件，话不多，偶尔解释两句手上在做什么。
- 转折：说到一半，她的目光扫过在线列表——那个熟悉的 ID 在。她手上的镊子停了半拍，继续往下讲，语速没变。
- 高潮：收尾，她说「今天就到这里」；弹幕里飘过一条：「衍：不错啊。」——和十年前频道里那些字，一模一样。
- 结尾：她盯着那三个字看了两秒，说了句「晚安」，关掉推流；另一头，他也把屏幕按灭，房间里很静。

### 情节安排（多线）

- 主线推进：直播线重启（L03 账号线活着）；「明牌相处」落地（L01）
- 辅线推进：L06 静默（老观众里有苏芒的旧梗弹幕，不点名）；L04 静默
- 事件线 / 任务线：重新开播与一场普通的直播
- 任务卡点（如适用）：无
- 感情线 / 关系线：温阮×傅衍舟——从「他在看，不能让她知道」到「他在看，她知道，且没打算让他装不知道」；关系停在最舒服的半步上
- 逻辑线：开播决定→立规矩→直播→看见 ID→他的弹幕→两块屏幕同时暗下去

### 人物关系和出场顺序

- 出场顺序：温阮（书桌前，开播准备）→ 直播间（老观众弹幕）→ 傅衍舟（另一块屏幕前，篇幅克制）→ 温阮（收播）
- 镜头准入：台词位＝温阮（少）、弹幕文字（群像）；傅衍舟全章无台词，只有动作位（调静音、看、发弹幕、关屏）
- 人物关系变化：温阮×傅衍舟（「他在看」从秘密变成两个人之间的常识——不解释，不点破，不越线）
- 视角/信息差：读者同时看着两块屏幕；直播间里没有人知道那条弹幕的分量
- 信息差触发点：第3点——「衍」的 ID 出现在在线列表时，用镊子的那半拍停顿，把「这条线通了」递给读者

### 结尾设定和钩子

- 结尾设定：推流关了，补光灯慢慢暗下去。书桌上，那个练习件的半边还差一点没收拾；她没有立刻起身。
- 章尾钩子：情感钩——屏幕暗了之后，那条「不错啊」还悬在弹幕栏最底下；十年里他说过很多次，这一次，她看见了。
