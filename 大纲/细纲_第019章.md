# 第19章 细纲：我看的是手

- 核心事件：月度业务分享获认可；送修方沟通后，她问出「你怎么找到我的」——他答：「我看的是手，不是名字。」公开短片识别路径揭开第一层。
- 字数目标：2500 字
- 字数口径：visible_chars_v1
- 阶段位置：发展期开端第19章；识别链解释（一）
- 单元ID/位置：V1-U4（第4拍：认可与识别链·一）
- 目标情绪：被认可的微光（分享会掌声是给方案的）→ 直面的紧（问题问出口）→ 落定（答案在公开处，不神秘）
- 主角目标/关键选择：她要弄清「他怎么找到的我」；关键选择＝只问机制、不问身份——她要先把事情还原成可核查的事实，再决定怎么面对
- 章节定位：推进
- 本章结构公式：业务分享（认可）＋单独场合（她问）＋他的回答（短片与手）＋她自查（把短片看回去）
- 章首钩子：悬念对话开局——「你怎么找到我的。」她问出口的时候，自己都愣了一下。
- 爽点：无强爽点；看点＝「谜底的一半是公开的」——十年被还原成一件可核查的事
- 本章标价：尺1（第2点）：公开短片的公开价——人人可查，却没几个人看见他看见的东西；尺2（第3点）：她问题的价——问出口，就等于承认「我想知道」
- 闭环状态：不闭环；F1 解释第一层（获得）；「名单上那个 ID 对没对上人」仍悬置（第 22 章）
- 本章禁止提前释放：不得确认「衍」＝傅衍舟；不得展开他的十年经历；本场对话不许被打断、不许欲言又止——机制问题当场答完
- 写手自由区：分享会的场面与提问密度、她问话前的铺垫动作、他回答时的语速与用词、短片回看的画面感
- 契约风险：契约安全

### 内容概括（五段式）

- 起因：月度业务会，她站在投影前讲方案：为什么六处裂要分两种走法。讲完，全组第一次用掌声把她留下——掌声是给方案的。
- 发展：会后送修方沟通结束，走廊只剩他们。她问了那句憋了一个月的话：「你怎么找到我的。」他答得平：「你们馆的那支短片。你的手，三个习惯，镜头扫过工作台的那几秒就够了。职名和单位，是公开的。」
- 转折：她追问：「就这些？」他说：「就这些。」然后补了那句：「我看的是手，不是名字。」——像在陈述一桩事实，没有修辞。
- 高潮：回到办公室，她把那支短片从头看完：镜头扫过的那几秒，习惯清清楚楚。她往椅背上一靠——原来答案一直挂在网上，等的是一个「看手」的人。
- 结尾：她说：「你没有用任何不该用的东西。」他答：「我用的东西，你都查得到。」她把短片的链接存进了那个和竹刀同格的文件夹。

### 情节安排（多线）

- 主线推进：方案与贡献在馆内第二次被公开认可；识别链机制落地（F1 解释第一层）
- 辅线推进：L01 从「他知我」的被动，推到「我看清了你怎么知道」的平等起点；L03 静默（她自查的是公开信息，没有任何泄露）
- 事件线 / 任务线：业务分享与送修方沟通日
- 任务卡点（如适用）：无
- 感情线 / 关系线：无显性；平等感从「被看见」进一步落到「看得见的规则」上
- 逻辑线：分享获认可→她发问→机制揭晓→她自查核实→机制归她掌握（信任以可验证为前提）

### 人物关系和出场顺序

- 出场顺序：温阮（分享会）→ 同事（提问群像）→ 傅衍舟（会后走廊）→ 温阮（办公室，回看短片）
- 镜头准入：台词位＝温阮、傅衍舟、主持人/同事两三名；唐时野可在沟通日背景位出现一次
- 人物关系变化：温阮×傅衍舟（从「他为什么知道」的悬置，到「他的知道经得起查」的落地）；温阮×自己（她第一次主动追一个答案）
- 视角/信息差：读者知道「三个习惯」背后是十年；她只拿到机制，还没对上那个 ID
- 信息差触发点：第4点——短片回看时，读者看见她终于站到了他当年的位置：隔着屏幕，认一双手
