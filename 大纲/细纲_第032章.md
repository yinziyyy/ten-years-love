# 第32章 细纲：调拨单

- 核心事件：备赛材料缺口：陆嘉树从省中心走正规调拨补齐（含准入流程）；傅衍舟克制吃醋——不改流程、不拦师兄、不替她拒绝，只把自己「原本想出手的渠道」收回了抽屉。
- 字数目标：2500 字
- 字数口径：visible_chars_v1
- 阶段位置：发展期主体第32章；备赛材料线与微醋点
- 单元ID/位置：V2-U1（第2拍：材料与微醋——师兄相助）
- 目标情绪：材料焦虑（卡在批次上）→ 师兄来了的暖（流程内的安心）→ 他不动声色的那点酸（克制）
- 主角目标/关键选择：她要把缺的料补齐且手续干净；关键选择＝坚持走准入流程、如实登记——师兄的好意收下，边界也照旧；他则选择什么都不做
- 章节定位：推进
- 本章结构公式：缺口（批次对不上）＋调拨（师兄走流程）＋醋（克制的动作）＋登记入册（合规闭环）
- 章首钩子：悬念陈设——材料单上的缺口不大，就卡在「批次对不上」这一行。
- 爽点：微甜点——师兄的「顺路」与他的「不动」
- 本章标价：尺1（第2点）：这批料的价——批次对不上，作品就上不了台；尺2（第4点）：能办却按下不办的价——克制也是成本
- 闭环状态：材料缺口闭环（缺口→调拨→入库→准入核验→登记）；微醋点不解决，留到后续发酵；L07 前置
- 本章禁止提前释放：不让他扣材料、为难师兄或替她拒绝帮助；陆嘉树不黑化、不越界；不写三角撕扯
- 写手自由区：清点单与批次编号的细节、便签的语气、库房口的偶遇构图、碎纸机那一声
- 契约风险：契约安全

### 内容概括（五段式）

- 起因：按备赛清单清点材料：缺一小批老料片，现库批次对不上，降级就得重排工序——作品等不起。
- 发展：她按流程报缺、等答复。第二天下午，省中心的正规调拨单到了——陆嘉树办的，附一张便签：「顺路的，别客气；手续都全。」
- 转折：材料入库、准入核验、登记入册，一样不落。他（傅衍舟）在库房口出现了一下，看了眼调拨单的经办人栏，什么也没说。
- 高潮：唐时野后来漏了一句：傅总把自己那边「能帮忙找一批」的渠道单，收回了抽屉——没说为什么。
- 结尾：她给师兄回消息：「到账，按流程走的，谢谢。」给傅衍舟发的是另一条：「材料齐了，进度表晚点发你。」

### 情节安排（多线）

- 主线推进：备赛材料合规到位（L02）；L07 前置（师兄温和相助，为第 47 章公开维护埋底）
- 辅线推进：L01 推到「他的克制第一次有具体动作」（收回渠道单）；L04 静默
- 事件线 / 任务线：材料缺口与正规调拨
- 任务卡点（如适用）：材料缺口＝进度卡点；功能＝信息揭示（她坚持流程）与关系变化（两个男人的分寸）；收束动作＝登记入册
- 感情线 / 关系线：温阮×陆嘉树（师兄妹的松弛与克制）；温阮×傅衍舟（他不动，她看得出，两个人都没说）
- 逻辑线：缺口→报缺→调拨→入库与核验→他收回渠道单→两条消息

### 人物关系和出场顺序

- 出场顺序：温阮（操作间，清点）→ 陆嘉树（接头交接，一段）→ 傅衍舟（库房口，一个动作）→ 唐时野（一句转述）
- 镜头准入：台词位＝温阮、陆嘉树（松弛）、唐时野（一句）；傅衍舟全章无台词，只有动作（看一眼、收抽屉）
- 人物关系变化：温阮×陆嘉树（帮助停在流程里，情愫不外露）；温阮×傅衍舟（醋被压住，分寸没破）
- 视角/信息差：读者知道他的醋与克制；她大概知道，也装不知道——两个人都给足了台阶
- 信息差触发点：第4点——「收回了抽屉」被转述出来时，读者比她知道得更多一点
