# 第8章 细纲：他连这个都有

- 核心事件：修复进入关键耗材期，老料生漆断货三个月；第二天全套材料出现在操作间——她开始给「恰好」记账。

- 字数口径：visible_chars_v1
- 阶段位置：开篇期第8章；危机与救援章
- 单元ID/位置：V1-U2（第4拍：甜点与疑点）
- 目标情绪：焦头烂额（断货）→ 悬空落地（材料到了）→ 心里那根弦被拨响（她开始记录「恰好」）
- 主角目标/关键选择：她要保住工期；关键选择＝把「追问」换成「记录」——像做检测一样，把每一次「恰好」记下来
- 章节定位：推进
- 本章结构公式：危机（断货）＋救援（材料到了）＋追问（唐时野打太极）＋清单+1＋深夜收线

- 闭环状态：断货危机闭环（危机→救援→复工）；兑现归属＝她的工期被保住；她付出的心理成本＝欠了一次说不清的人情

- 契约风险：契约安全

### 内容概括（五段式）

- 起因：清洗告一段落，修复进入补配与地仗阶段——主用材料老料生漆，库房存量见底。供应商报价单发来：至少等三个月。
- 发展：工期表上，三个月等于「这单到冬天才能见光」。她坐在操作间对着料单发呆，把替代方案划了一版又一版。
- 转折：第二天清早，操作间里码着全套材料——老料生漆、金粉、补配瓷片，连养护用的木贼草都备了两份。唐时野：「傅总说，这些东西在仓库睡觉，不如让它们干活。」
- 高潮：她追出去问「傅总怎么知道我要什么」，唐时野回头笑：「您要是不信，回头自己问他。」她张了张嘴，把这句咽了回去——回到桌前，在便签上加了一行：「2. 生漆——恰好。」
- 结尾：深夜，她给苏芒发消息：「假如有个人，比你自己还知道你要什么……」苏芒秒回一串问号；她只回了两个字：「没事。」关掉手机——窗外，傅氏大厦的灯还亮着。

### 情节安排（多线）

- 主线推进：L02 材料危机与复工；L01「恰好」清单升级为可对账的证据链雏形
- 辅线推进：L06 苏芒被卷入「她开始说起这个人」的进程；L04 静默
- 事件线 / 任务线：耗材采购与工期管理
- 任务卡点（如适用）：老料生漆断货＝进度卡点；功能＝代价兑现（专业修复不能降格）与推进（救援后的复工）
- 感情线 / 关系线：温阮×傅衍舟（无直接对话，但他的「兜底」把存在感又加了一层）；她第一次向苏芒泄漏半句心事
- 逻辑线：料断→工期危→材料隔夜到位→追问无果→她把疑问改成记录→深夜向苏芒泄漏又收回→清单成为两段线的账本

### 人物关系和出场顺序

- 出场顺序：温阮（操作间/电话）→ 唐时野（清早送料）→ 苏芒（深夜短信，线上）
- 镜头准入：台词位＝供应商电话（画外）、唐时野、苏芒（短信）；温阮内心与动作位为主
- 人物关系变化：温阮×唐时野（打太极的「知情者」形象稳固）；温阮×苏芒（她把「这个人」的存在第一次说出口半句）
- 视角/信息差：读者能拼「他有备而来」，她停在「欠了人情」的层面；苏芒不知道「这个人」就在她眼前
