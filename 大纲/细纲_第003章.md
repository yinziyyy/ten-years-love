# 第3章 细纲：只有阿阮知道的事

- 核心事件：傅衍舟二次到馆与温阮单独对接；他说出只有「阿阮」本人才知道的八年前作品细节，并点明：他要的「阿阮修」，不是要逼她承认什么。
- 字数目标：2500 字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期第3章；黄金三章之三
- 单元ID/位置：V1-U1（第3拍：决定性行动——她争取「一天时间」）
- 目标情绪：戒备对峙（她准备用「跟我无关」挡回去）→ 心惊（他说的每一句都指她）→ 动摇（他最后一句让拒绝变得很难）
- 主角目标/关键选择：她要确认他到底知道多少、想要什么；关键选择＝不承认、不否认，只争取「一天时间」（守住底线，又给自己留门）
- 章节定位：推进
- 本章结构公式：单独对接（错位对称）＋细节揭底（只有阿阮知道的事）＋立场试探（他不逼她认）＋让步与悬念（给我一天）
- 章首钩子：悬念对话开局——「傅先生找的这个人，我们真的不认识。」「我知道。」
- 爽点：无显性爽点；看点＝信息差翻面——她第一次意识到「被看见」到这种程度，恐惧与悸动是一体两面
- 本章标价：尺1（第3点前）：八年前那场直播的独占性——当晚回放在公开侧已删、切片未流传（仅主播本人后台可查），对外部人而言「当晚在场」是唯一入场券；尺2（第4点前）：「阿阮」的规矩——不接馆方、不露脸（圈内人尽皆知），拒绝他＝守规矩
- 闭环状态：本章不闭环。她「获得」信息（他知情的深度）；兑付（接与不接）扣在第4章
- 本章禁止提前释放：他是「衍」（ID）；他为啥知道她＝马甲的完整机制；旧案关联
- 写手自由区：资料室的安静质感、他说话的方式（少形容词、多器物细节）、她两次想反驳又咽回去的瞬间
- 契约风险：契约安全

### 内容概括（五段式）

- 起因：周明德把「对接送修方」的差事压给温阮——「他点名要检测记录员来谈。」她愣了：组里论资历、排职称，评审和署名资格都挂在职称上，这样的差事从没轮到过她；老周只摆摆手：「别问我为什么。人家点的是你。」
- 发展：资料室，一对一对坐。她摆出「我与阿阮无关」的姿态。他不接话，只把话题落回盏：「这盏碎过两次。第一次修它的人，收笔是回锋的——你昨天在检测单上，也是这么写的。」
- 转折：他说起八年前：一只没人肯修的雪霁瓶，弹幕都劝她放弃，主播却留了一道裂不补——「它裂得有道理。」他复述的语速很慢，像在拆一件保存了很久的东西。
- 高潮：她问「你到底是谁」。他说：「我是那天在线的人。那天灯有点暗，你抱怨过一次。」——那天夜里，直播间只有十二个人。
- 结尾：他没有逼任何答案，起身前只留一句：「修不修在你。它等了很久，我最不缺的就是耐心。」她捏着门把手，站了很久。

### 情节安排（多线）

- 主线推进：他成为「知道她是谁」的第一人（仅彼此之间心照不宣），L03 推到「被一个人精准锁定」；L01 推到「面对面递交十年的一角」
- 辅线推进：L02 推到「送修方点名她对接」——她在馆内的位置被动提升；L05 微电波保持静默
- 事件线 / 任务线：送修方对接会（她本想用它划清界限，反被将了一军）
- 任务卡点（如适用）：无
- 感情线 / 关系线：温阮×傅衍舟（陌生→她第一次意识到「有人看她的直播看到这种程度」）；她的防线出现第一道缝
- 逻辑线：他点名她对接→她摆姿态→他用细节证明知情→她心理防线被撬动→他想确认「接不接」但不逼→悬念留到第4章

### 人物关系和出场顺序

- 出场顺序：周明德（派活）→ 傅衍舟与温阮（资料室一对一）
- 镜头准入：整场戏二到三人；周明德只出现在开头与结尾的门口；核心是两个人的对话位
- 人物关系变化：温阮×傅衍舟（甲方乙方→「他知道她是谁」的心照不宣）；她对「被安排」的姿态从硬到软
- 视角/信息差：读者全程领先。她在评估「他知道多少」；读者已能拼出「他是老观众」的轮廓（第7章把 ID 递到台面）。她的误判：也许他只是普通的资深粉丝
- 信息差触发点：第4点——他复述八年前细节时，读者知道「他说的是她」，她却装作在听「别人的故事」——双重解释提醒读者一次

### 结尾设定和钩子

- 结尾设定：她走出资料室前回头看了一眼——他坐过的椅子还保持着朝向她的角度。她把这间屋子的排风扇打开，像要吹散什么。
