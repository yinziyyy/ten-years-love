# 江城市博物馆（势力）

- 名称：江城市博物馆
- 定位：市属综合博物馆；非遗项目主场
- 核心目标：完成年度重点项目、申办省级非遗资质
- 关键人物：周明德（馆长）、谢云筝（修复组组长）、温阮（修复师，资历最浅）
- 与主角关系：主场与体制内身份来源；荣誉与束缚并存

## 修复组结构

- 组长：谢云筝；组员含温阮与数名修复师；共用工位与设备紧张，「顺手」是奢侈品
- 温阮现状：修复师（馆内最年轻）；无独立操作间（接单后启用南侧独立间）

## 流程与规矩（B 级落档）

- 贵重器物修复流程：入馆检测 → 方案定稿 → 组内评审（可触发方案比稿）→ 逐段修复 → 验收 → 署名归档
- 比稿规则：发起需全组同意；三天出方案、全组评审、馆长裁决（第10章立起）
- 评审列席：评审席＋送修方列席位；送修方可作列席陈述（第15章用）
- 录像备案：贵重器物修复全程录像、逐日归档（第6章立起；后续作为物证接口）

## 场景段（B 级落档·本批用到）

- 修复组工作室：行政楼后侧一层大间；进门走廊尽头是独立操作间（南侧靠窗）
- 独立操作间：无影灯×1（新装可调角度）、恒温柜×1、工作台×1、工具抽屉×1
- 检测台：大间中央（共用）；资料室/档案室：副楼二层；会议室：行政楼一层（长桌+投影）
- 评审小厅：行政楼一层，长桌＋样品灯；日常兼会议室
