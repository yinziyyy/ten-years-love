# 傅衍舟（男主）

## 主角卡

- 姓名：傅衍舟
- 性别：男
- 角色定位：男主——「蓄谋已久」的守望者，用十年把隔着屏幕的喜欢走成并肩
- 身份标签：傅氏资本掌门人 / 「阿阮」直播间十年榜一老粉（ID「衍」）
- 外貌特征：冷眉深眼、坐姿永远笔直；袖扣每天换；说话时习惯性转袖扣半圈
- 性格关键词：对外冷面利益至上、对内偏执深情、行动派（先做后说）、克制
- 核心目标：让温阮以自己的名字、自己的手艺站到台前——然后并肩
- 核心动机：十年前被她「把破碎的东西变回完整」的专注打动；十年如一（情感驱动）
- 致命弱点：习惯「安排」而非「询问」——怕「十年」在她眼里变成监视与冒犯
- 口头禅/标志动作：「等你」/ 转袖扣；碰器物前先净手

- 说话方式：少形容词、多器物细节；信息给一半，留白给对面

- 禁区：不说教、不炫耀资源、不替她做决定
