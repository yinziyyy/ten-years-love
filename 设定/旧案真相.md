# 旧案真相（作者侧权威）

> 本文件是 2006 年旧案的完整作者真相与证据分工。卷纲/细纲只负责按节奏释放，不得改写事实。

## 一、事件全貌

2005 年，阮秀和受傅家委托修复磕损的霁蓝盏（A），修毕留暗记（收笔回锋、半个「和」字）。

2006 年技艺展，阮秀和携自有旧瓷盘修复作品《碎玉重圆》（B）参展；傅家同意把 A 作为辅助案例借展，两件器物同批装箱。时任收件协调的柳承业看中 B 的双技成果，在入场前的中转环节，用其工作室一件相近年代、相近器型的失败试修盘替换 B，并把替换盘的检查照片、尺寸记录等归入阮秀和名下。当日中转环节留下过展务组的《2006 年技艺展展品中转暂存签收单》——盘类一件在该单上有「暂存—二次签收」两个时间点，签收关系栏可见柳承业（收件协调）与工作室人员代签（该单只记录时间、件数与签收，不提及换件，须与其他证据交叉）。

替换盘存在过度磨削与遮盖损伤。评议据此认定阮秀和损伤旧瓷、虚报修复成果——这是当年的行业结论，不默认存在刑事判决。

阮秀和提出过异议，但她自己的过程照片无法单独证明实际交进展馆的是哪只盘；收件记录又被修改，申诉受阻。

柳承业把真 B 换名、冒署为工作室成果，借此申报代表案例，获得合作与声誉。展后 B 以工作室案例名义留在原承办机构，后随旧项目样本与档案转入省文物修复研究中心旧样本库，长期未公开陈列；作者、题名与来源被改写。阮家不知道去哪里寻找，保管方也没有重新核验作者。

A 没有被替换。傅家为避免争议退展，带回 A 及己方原始装箱资料，没有继续帮助阮秀和查证——傅家的问题是消极切割，不是参与掉包。

## 二、关键中转记录（选定，唯一口径）

《2006 年技艺展展品中转暂存签收单》：

- 谁形成：当年技艺展承办机构展务组当班收件人填制；「收件协调」一栏署柳承业；盘类一件栏有工作室人员的「二次签收」签名。
- 谁保管：随旧展档案归档；后随旧项目样本与旧展档案一并归集，转入省文物修复研究中心档案室（与 B 的样本档案同一归集批次）——这也是第 101 章能顺着正式调阅链找到它的原因。
- 为什么保留：旧项目档案按制度整体归集，从未有人就该案调过此卷宗；当年申诉只烧到被修改的「收件记录」，没人想到调展务组的暂存签收单。
- 温阮通过什么途径取得：第 99 章调阅获批后，第 101 章经省中心档案调阅程序取得复印件（承接第 97 章提出的正式调阅申请）。
- 与运输票据、冒署资料互相印证的点：①签收单上「暂存—二次签收」两个时间点，与司机保留票据的临时改送时段衔接；②单上盘类一件的临时编号，与冒署留样资料所引「代表案例」编号一致——即被冒署的正是该盘。
- 边界：该单只记录时间、件数与签收关系，不写动机、不写换件，不能单独包办定责；需与运输票据、冒署留样资料、B 的烧成缺陷与缺口轮廓交叉。

> 全书统一以本签收单为准，不再使用「中转指令、签收或出入记录」的三备选写法；也不新增知道全部真相的万能证人。

## 三、证据分工

| 证据 | 作用 | 浮出/获得节点 |
|------|------|----------------|
| A 的暗记 | 确认修复者是阮秀和 | 第 2、9 章（她私认）；第 77 章起作为正式比对的起点 |
| 傅家原始装箱资料 | 证明送出时的器物记录 | 第 77-80 章，温阮提出请求，傅衍舟提供 |
| 后来找到的收件资料 | 与原始记录比较，发现尺寸、编号或中转记录异常 | 第 77 章（清单异常） |
| 司机保留的运输票据 | 证明临时改送地点和签收关系——据此锁定后续调阅方向；司机当年不知箱内发生了什么，不承担全部解释 | 第 90 章找到人、第 96 章获得票据 |
| 旧样本编号线索 | 指向真品 B 在省中心旧样本库的档案位置 | 第 97 章由流转资料查到；温阮提出正式调阅申请 |
| B 的烧成缺陷、原缺口轮廓与过程照片 | 确认找到的是真品 | 第 99 章经批准开箱比对 |
| 《2006 年技艺展展品中转暂存签收单》 | 证明盘类一件的中转暂存与「二次签收」时间及签收关系；与运输票据时段、冒署留样编号互相印证 | 第 101 章随正式档案调阅取得 |
| 柳工作室的冒署留样资料 | 证明他占有成果并从中获利 | 第 101 章取得并交叉核对 |

> 不能只凭「柳获利」认定他主使，也不能让霁蓝盏上的一个暗记或任何单一文件包办定责——中转签收单只记录时间、件数与签收关系，须与运输票据、冒署留样、器物特征交叉。

## 四、调查分工（主角代理权）

- 温阮：提出疑点、决定调查方向、比对器物与记录、推动独立复核；关键节点（第 77、90、96、97、99、101、102 章）由她的行动链推进。
- 傅衍舟：提供她请求的傅家材料；不替她暗中完成全部调查和送审。
- 真 B 的调阅与验证走保管机构的正式流程，不靠任何个人私下取走；第 104-105 章的到场展示按保管机构正式借展程序办理。
- 旧案证据的主要核验在第 99-102 章完成；第 104-105 章只展示已经核验完成的器物与证据，不允许台上突然获得决定性文件；第 109-111 章完成相应处理与名誉恢复，与事实核验分开呈现。

## 六、柳承业的动机与防线

- 动机：2006 年的冒署让他拿到代表案例与行业资源；二十年来他是旧案的既得利益者。
- 防线：以程序与身份压人——担任评审、动用「协调」名义；他不怕作品，怕的是当年的物证与流转记录复活。
- 底线：其责任必须由《2006 年技艺展展品中转暂存签收单》＋司机运输票据＋冒署留样资料等可核验材料交叉落实，不能靠推断。
